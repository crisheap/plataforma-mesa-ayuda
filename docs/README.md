## Cómo leer el estado de los requerimientos

Las columnas «Estado» del ERS v2 y los hallazgos H-01 a H-17 (sección 10) describen el **diagnóstico del backend v1**, hecho antes de implementar la versión 2.0. Funcionan como línea base.

El estado actual de la implementación está en el [README principal](../README.md#trazabilidad-requerimientos--código): ahí se indica qué módulo cubre cada requerimiento y qué hallazgos se corrigieron.
